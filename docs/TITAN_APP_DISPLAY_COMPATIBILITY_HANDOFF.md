# Titan App Display Compatibility Handoff

STATUS=IMPLEMENTATION_HANDOFF

SOURCE_REPO=sableos-project/platform_sable
BUILD_CODE_CHANGED=NO

FLASH_ENABLEMENT=NO

## Purpose

Define the implementation boundary for the Titan-family per-app display compatibility feature. This handoff closes the gap between previously documented Mini Mode / Rotation Control and the full product requirement for custom per-app display profiles such as 16:9.

```text
APP_DISPLAY_COMPATIBILITY_PROFILES=YES
PER_APP_DISPLAY_PROFILE=YES
PER_APP_ASPECT_RATIO=YES
CUSTOM_16_9_PROFILE=YES
MINI_MODE_AS_PROFILE=YES
ROTATION_CONTROL_AS_PROFILE_DIMENSION=YES
KEYBOARD_SAFE_PROFILE=YES
```

## Implementation boundary

N0 may carry UI and persistent per-app profile state, but must not claim backend display forcing works until validated on Android 16.

```text
N0_UI_ALLOWED=YES
N0_PROFILE_STORAGE_ALLOWED=YES
N0_NOOP_STATE_ALLOWED=YES
N0_VALIDATION_HOOKS_ALLOWED=YES
WINDOW_MANAGER_BACKEND_REQUIRED=YES

```
