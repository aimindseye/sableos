# N1B system surface scope

Status: **approved planning contract / documentation-only**

N1B must evaluate SableOS as a keyboard-first system experience. This document
binds system and first-party surfaces so the image does not become a thin app
bundle on top of an unreviewed system shell.

```text

BUILD_CODE_CHANGED=NO
DEVICE_CODE_CHANGED=NO
IMAGE_BUILD_AUTHORIZED=NO

```
