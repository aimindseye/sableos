# N1B Phase 16: Titan2 Executable-Plan Draft

## Purpose

Phase 16 is a review-only executable-plan draft gate for Titan2/N1B.

It consumes the Phase 15 manual authorization package and produces a structured deployment-plan draft that a human can review before any execution authorization is discussed.

Phase 16 does not authorize execution. It does not contact the device, emit runnable shell commands, run ADB, run fastboot, resize logical partitions, flash images, erase userdata, reboot, mutate AVB, change slots, unlock, publish, or production-sign.

## Owner authorization basis

Phase 16 exists only because the owner approved:

```text
APPROVE_PHASE_16_EXECUTABLE_PLAN_DRAFT_ONLY=YES
AUTHORIZE_EXECUTION=NO
```

This approval authorizes only creation of a future-looking review artifact.

## Draft content

Phase 16 emits structured **action intents**, not runnable commands.

The review package may describe these action-intent families:

```text
VERIFY_OPERATOR_INTENT_AND_STOP_CONDITIONS
VERIFY_RESTORE_PATH_AND_USERDATA_POLICY
VERIFY_DEVICE_IDENTITY_FASTBOOTD_AND_ACTIVE_SLOT
PLAN_ACTIVE_SYSTEM_LOGICAL_PARTITION_GROWTH
PLAN_SYSTEM_IMAGE_DEPLOYMENT
PLAN_AVB_CHAIN_DECISION
PLAN_POST_CHANGE_ACCEPTANCE
PLAN_ROLLBACK_OR_STOP
```

Every action intent must include:

```text
executable_command=NO
manual_execution_authorization_required=YES
operator_review_required=YES
stop_if_unmet=YES
```

## Output states

```text
N1B_PHASE_16_EXECUTABLE_PLAN_DRAFT=PASS_REVIEW_DRAFT_READY
N1B_PHASE_16_EXECUTABLE_PLAN_DRAFT=BLOCKED
```

`PASS_REVIEW_DRAFT_READY` means only that a non-executable draft exists for review. It does not authorize any command execution.

## Canonical post-merge flow

After this PR is merged, run from merged `main`:

```bash
cd /srv/data/sable-build/sableos/repo

git fetch origin main
git switch main
git merge --ff-only origin/main

bash build/gates/n1b-phase-16-executable-plan-draft-contract.sh

SABLEOS_DEVICE=titan2 \
SABLEOS_RELEASE_VERSION=N1B \
bash build/local-ci/run.sh full
```

Then assemble the Phase 16 draft:

```bash
bash build/titan2/assemble-n1b-phase-16-executable-plan-draft.sh \
  --phase15-json /srv/data/sable-build/evidence/titan2/n1b-phase-15-manual-authorization-package/20260928_205352/offline-authorization-package/phase15-manual-authorization-package.json \
  --phase14-json /srv/data/sable-build/evidence/titan2/n1b-phase-14-final-preflight-approval/20260928_204633/offline-approval/phase14-final-preflight-approval.json \
  --phase13-json /srv/data/sable-build/evidence/titan2/n1b-phase-13-flash-plan-proposal/20260928_202350/offline-proposal/phase13-flash-plan-proposal.json \
  --artifact-manifest /srv/data/sable-build/release-registry/titan2/N1B/462839cfcc362e4f4ed93d8a8dabf059885452b1.json \
  --restore-report /srv/data/sable-build/artifacts/titan2/stock-firmware/unihertz-device-fota-20260922 \
  --system-image /srv/data/sable-build/workspaces/titan2-n1b/out_sable_t2_n1_sable_gsi/target/product/tdgsi_arm64_ab/system.img
```

No command generated by Phase 16 is runnable. Any later execution boundary requires a separate owner authorization.
