# N1B Setup Wizard and first-boot scope

Status: **approved planning contract / documentation-only**

Setup Wizard / First Boot is a first-class N1B requirement because Titan 2 UX
evaluation starts at first boot, before the user reaches Sable Start.

```text
N1B_INSTALL_WIZARD_SCOPE=YES
SETUP_WIZARD_FIRST_BOOT_REQUIRED=YES
PHYSICAL_KEYBOARD_VERIFICATION_REQUIRED=YES
CRITICAL_TEXT_ENTRY_GATE_REQUIRED=YES
DOCUMENTATION_ONLY=YES
BUILD_CODE_CHANGED=NO
DEVICE_CODE_CHANGED=NO
FLASH_AUTHORIZED=NO
```

## Required first-boot flow

N1B must implement or explicitly block/defer the approved first-boot flow:

```text
WELCOME_STEP=REQUIRED
ACCESSIBILITY_ENTRY=REQUIRED

```

## Temporary fallback rule

If N1B cannot include a fully implemented Sable Setup Wizard, the PR that defers
it must state:

```text
SETUP_WIZARD_TEMPORARY_FALLBACK=<exact fallback>
KEYBOARD_VERIFICATION_BLOCKED_REASON=<reason>
CRITICAL_TEXT_ENTRY_RISK=<risk>
N1B_LOAD_RISK_ACCEPTANCE_REQUIRED=YES
NEXT_STAGE_OWNER=<owner>
```
