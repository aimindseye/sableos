## Phase 3 subdeliverables — no scope contraction

**3A — independent full-stock static topology:** Use all four byte-pinned V01.00.14 partitions, not only JARs or PR347 caller references. Index every file; decode supported APK/JAR/DEX, APEX payloads, native DT_NEEDED, init and relevant configuration. Enumerate real DEX `invoke-*` opcodes, defined members, exact class hierarchy and artifact ownership with source offsets. Report every undecoded binary XML/APEX/OAT/VDex, JNI/Binder, reflection, modem/UA and all missing live-call edges in a complete OPEN_BOUNDARIES report. Restore no images to a device; do not import proprietary binaries to GitHub. The first package is **a static census, not a full live call-chain proof**.

**3B — OEM-versus-upstream behavior:** Use targeted JADX/Ghidra across all relevant owners found by 3A; verify callsite/bytecode exception/branch/registration/reset behavior against revision-matched AOSP16 and post-r2 updates; record probable upstream changes vs OEM-specific changes with attribution uncertainty. The 32-owner/84-member Phase2C first-review sample is a UI convenience only, never a graph limit.

**3C — runtime correlation:** Reuse preserved sanitized factory-stock tray1/tray2 captures first. Outgoing and incoming voice, boot/IMS registration, bearer setup, SIM routing, hold/handover, failure/fallback and recovery each get independent time-ordered evidence. If full edges cannot be resolved, request explicit approval and a verified stock boot before read-only device capture. No device flash, calls or radio toggles are authorized by this roadmap.

**3D — stock behavioral ledger:** Mark each node/edge with exact source/evidence and `RUNTIME_OBSERVED`, `STATIC_EXACT`, `CONFIG_ONLY`, `HYPOTHESIS` or `UNKNOWN`; maintain all unproven branches. This feeds Phase 4 closure, then Phase 5 implementation classification.
