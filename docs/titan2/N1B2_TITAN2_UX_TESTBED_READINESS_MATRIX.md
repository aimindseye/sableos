# Titan2 N1B2 UX testbed readiness matrix

Status: **N1B2 image-packaging gate input**

This matrix is not an audit note. It is a release-build input for N1B2 GSI image
packaging. The N1B2 image-candidate build path must fail unless every row below
is one of:

```text
PASS
POLICY_PRESENT
EXPLICIT_BOUNDED_DEFERRAL
```

No row may be `TODO`, `UNKNOWN`, `PENDING`, `FAIL`, `NO`, or left blank when
building an N1B2 image candidate.

```text
N1B2_TITAN2_UX_TESTBED_READINESS_MATRIX=YES
N1B2_UX_TESTBED_ALLOWED_STATUS_SET=PASS|POLICY_PRESENT|EXPLICIT_BOUNDED_DEFERRAL
N1B2_UX_TESTBED_FAIL_ON_UNDECIDED_ROW=YES
N1B2_UX_TESTBED_PACKAGING_GATE_REQUIRED=YES
N1B2_UX_TESTBED_TARGET_FILES_MARKER_REQUIRED=YES
N1B2_FLASH_ALLOWED=NO_SEPARATE_GATE_REQUIRED
PUBLIC_RELEASE=NO
PRODUCTION_SIGNING=NO
```

## Boundaries for explicit deferrals

The explicit deferrals above are bounded as follows:

```text
CONTACTS_PHONE_ALPHABET_RAIL_DEFERRAL_BOUND=N1B2 may boot without a final alphabet rail fix only if the issue is carried as an acceptance-row failure/known deviation and Phone/Contacts remain usable for basic entry and lookup.
READER_THEME_VAACHAK_DEFERRAL_BOUND=N1B2 may defer Vaachak import or final Reader theme parity only if Reader does not block setup, HOME, command/search, or global theme propagation validation.
MEDIA_PORTRAIT_DENSITY_DEFERRAL_BOUND=N1B2 may defer final media portrait-density polish only if Sable Media launches and the portrait-density gap is recorded as a bounded visual issue, not a blocker to first UX testbed boot.
```

## Image-packaging requirements

The N1B2 image-candidate build path must verify all of the following before
artifact registration:

```text
N1B2_UX_TESTBED_MATRIX_GATE=PASS
N1B2_PRODUCT_PROFILE_GATE=PASS
N1B2_SETUP_WIZARD_GATE=PASS
N1B2_SABLE_HOME_GATE=PASS
N1B2_TARGET_FILES_PRODUCT_CLOSURE_MARKER=PASS
N1B2_TARGET_FILES_UX_TESTBED_MARKER=PASS
N1B2_ARTIFACT_REGISTRATION_BLOCKS_ON_MATRIX=YES
```

The generated Android workspace profile must place the UX matrix marker in the
system image target-files package at:

```text
SYSTEM/etc/sableos/n1b2/ux-testbed-readiness.env
```
