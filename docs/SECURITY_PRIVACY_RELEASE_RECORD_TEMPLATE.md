# SableOS Security / Privacy Release Record Template

Status: **normative evidence template**.

Use this template for device-port qualification, release-candidate closure and production release evidence. Development milestones may leave production-only fields as `NOT_APPLICABLE` or `NOT_RUN`, but must not fabricate a pass.

The template implements `SECURITY_PRIVACY_ASSURANCE_STANDARD.md` and `HARDWARE_SECURITY_CAPABILITIES.md`.

## Identity

```text
SABLEOS_ASSURANCE_STAGE=DEVELOPMENT|RELEASE_CANDIDATE|PRODUCTION
SABLEOS_DEVICE=
SABLEOS_SOC=
SABLEOS_ANDROID_BASELINE=
SABLEOS_BUILD_ID=
SABLEOS_BUILD_VARIANT=userdebug|user
SABLEOS_SOURCE_MANIFEST_SHA256=
SABLEOS_RELEASE_RECORD_SHA256=
```

## Risk / exception record

Repeat for each open risk or mandatory-control exception:

```text
risk_id=
control_id=
affected_scope=
severity=LOW|MEDIUM|HIGH|CRITICAL
status=OPEN|MITIGATED|ACCEPTED_DEVELOPMENT_ONLY|CLOSED
technical_reason=
compensating_control=
review_or_expiry_condition=
evidence=
```

Absence of an optional hardware capability is **not** a risk exception. Record it using `AVAILABLE=NO`, `ENABLED=NOT_APPLICABLE`, `VALIDATED=NOT_APPLICABLE`.

## Closure

Typical development closure:

```text
SABLEOS_ASSURANCE_STAGE=DEVELOPMENT
SABLEOS_SECURITY_PRIVACY_RECORD=PASS
SABLEOS_PRODUCTION_SECURITY_CLAIM=NO
```

Typical production closure requires at minimum:

```text
SABLEOS_ASSURANCE_STAGE=PRODUCTION
SABLEOS_SELINUX=ENFORCING
SABLEOS_AVB=VERIFIED
SABLEOS_BOOTLOADER_STATE=LOCKED
SABLEOS_SECURITY_PATCH_LEVEL_STATUS=VERIFIED
SABLEOS_UNRESOLVED_CRITICAL_SECURITY_RISKS=0
SABLEOS_UNEXPLAINED_SABLE_NETWORK_EGRESS=0
SABLEOS_MANDATORY_TELEMETRY=NO
SABLEOS_PRIVACY_INVENTORY=PASS
SABLEOS_SOURCE_PROVENANCE=PASS
SABLEOS_ARTIFACT_MANIFEST=PASS
SABLEOS_UPDATE_RECOVERY=PASS
SABLEOS_SECURITY_PRIVACY_RECORD=PASS
```

A production record may include `NOT_APPLICABLE` hardware capabilities without weakening the portable baseline.
