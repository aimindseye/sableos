# SableOS Security / Privacy Release Record Template

Status: **normative evidence template**.

Use this template for device-port qualification, release-candidate closure and production release evidence. Development milestones may leave production-only fields as `NOT_APPLICABLE`, `NOT_INTEGRATED` or `NOT_RUN`, but must not fabricate a pass.

The template implements `CORE_PRODUCT_MODEL.md`, `SECURITY_PRIVACY_ASSURANCE_STANDARD.md`, `HARDWARE_SECURITY_CAPABILITIES.md`, and `KERNEL_SECURITY_UPDATE_POLICY.md`.

## Risk / exception record

Repeat for each open risk or mandatory-control exception:

```text
risk_id=
control_id=
affected_scope=
severity=LOW|MEDIUM|HIGH|CRITICAL
status=OPEN|MITIGATED|ACCEPTED_DEVELOPMENT_ONLY|CLOSED
technical_reason=
compensating_control=
review_or_expiry_condition=
evidence=
```

Absence of an optional hardware capability is **not** a risk exception. Record it using `AVAILABLE=NO`, `ENABLED=NOT_APPLICABLE`, `VALIDATED=NOT_APPLICABLE`.

Lack of safe independent kernel-update support on a device is likewise not automatically a SableOS device-admission failure. Record the kernel-update capability limitation and security-maintenance consequences honestly.

A product surface classified `DEVICE_UNAVAILABLE` or intentionally not shipped must have a product rationale when the release otherwise claims the revised core product.

## Closure

Typical substrate/development closure:

```text
SABLEOS_ASSURANCE_STAGE=DEVELOPMENT
SABLEOS_CORE_PRODUCT_STAGE=SUBSTRATE
SABLEOS_CORE_PRODUCT_MODEL=PASS
SABLEOS_HOME_STATUS=NOT_INTEGRATED
SABLEOS_HUB_STATUS=NOT_INTEGRATED
SABLEOS_AOD_STATUS=NOT_INTEGRATED
SABLEOS_AGENT_STATUS=NOT_INTEGRATED
SABLEOS_VOICE_STATUS=NOT_INTEGRATED
SABLEOS_SECURITY_PRIVACY_RECORD=PASS
SABLEOS_PRODUCTION_SECURITY_CLAIM=NO
```

Typical production closure requires at minimum:

```text
SABLEOS_ASSURANCE_STAGE=PRODUCTION
SABLEOS_CORE_PRODUCT_STAGE=PRODUCTION
SABLEOS_CORE_PRODUCT_MODEL=PASS
SABLEOS_DEFAULT_APP_MATRIX=PASS
SABLEOS_AOSP_FOUNDATION_PRESERVED=PASS
SABLEOS_SELINUX=ENFORCING
SABLEOS_AVB=VERIFIED
SABLEOS_BOOTLOADER_STATE=LOCKED
SABLEOS_SECURITY_PATCH_LEVEL_STATUS=VERIFIED
SABLEOS_UNRESOLVED_CRITICAL_SECURITY_RISKS=0
SABLEOS_UNEXPLAINED_SABLE_NETWORK_EGRESS=0
SABLEOS_MANDATORY_TELEMETRY=NO
SABLEOS_PRIVACY_INVENTORY=PASS
SABLEOS_LANGUAGE_BASELINE=PASS
SABLEOS_SOURCE_PROVENANCE=PASS
SABLEOS_ARTIFACT_MANIFEST=PASS
SABLEOS_UPDATE_RECOVERY=PASS
SABLEOS_SECURITY_PRIVACY_RECORD=PASS
```

A production record may include `NOT_APPLICABLE` hardware capabilities without weakening the portable baseline.

If a release contains a K1/K2 kernel security update, `SABLEOS_KERNEL_SECURITY_UPDATE=PASS` is additionally required. If kernel inputs are unchanged, bind the existing sealed `SABLEOS_KERNEL_BASELINE=PASS` instead of inventing a kernel-update record.
