# Zinwa Q25 SableOS port plan — retired

Status: **RETIRED / NOT PLANNED**

SableOS is no longer planning engineering investment in the Zinwa Q25.

The project has acquired the **Unihertz Titan 2** and **Unihertz Titan 2 Elite**,
which cover the immediate MediaTek / physical-keyboard / compact-display
portability goals more directly, while the **Zinwa Q27** remains the preferred
future integrated/full-QWERTY candidate if its shipped hardware qualifies.

Q25 is therefore removed from:

- the active device roadmap;
- portability sequencing;
- release planning;
- acquisition/investment planning;
- device-specific implementation work.

Historical references to Q25 community repositories may remain in research notes
when they provide useful keyboard/keymap behavior examples. Those references do
not make Q25 a SableOS target.

Current device path:

```text
Pixel 7 / panther
    -> Titan 2
    -> Titan 2 Elite
    -> Zinwa Q27
```

Use `NON_PIXEL_DEVICE_ROADMAP.md`, `TITAN2_GSI_PLAN.md`,
`TITAN2_KEYBOARD_FIRST_REFERENCE.md`, and
`CAMERA_ENHANCEMENT_ROADMAP.md` for current planning.
