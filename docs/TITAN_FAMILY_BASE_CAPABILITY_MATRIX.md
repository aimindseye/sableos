## Purpose

This document prevents N0 implementation drift by defining which manual-derived features can be treated as shared Titan-family base requirements and which features remain gated or device-specific.

Shared base means SableOS implementation may create common Titan-family UX, Settings entries, app surfaces, test plans, and validation gates. It does not mean the feature is proven functional on a Sable build.
